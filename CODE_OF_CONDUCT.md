# Code of conduct

Treat participants respectfully. Discuss code and ideas without personal attacks. Harassment, threats, discriminatory abuse, sexual harassment and publishing another person's private information are not acceptable.

These rules apply to project issues, pull requests and other project-managed spaces. Maintainers may edit or remove content, close discussions or restrict participation to enforce them. Decisions should consider context and be applied consistently.

For a public moderation request, contact the repository owner in the relevant discussion without repeating harmful or private material. For a private report, use a contact method the owner lists on their GitHub profile; do not publish sensitive details while requesting a private channel. A dedicated confidential conduct-reporting address has not yet been established.
