# Security reporting

Do not disclose vulnerabilities, exploit details, private paths or credentials in public issues.

The intended confidential reporting channel is [GitHub private vulnerability reporting](https://github.com/zsoujin/auvora/security/advisories/new). It must be enabled and checked before the first public release. If the page is unavailable, do not post the details publicly; ask the repository owner for a private reporting channel without including sensitive information. A separate security email address has not been designated.

Include the affected version, Windows version, reproduction steps, expected and actual behavior, impact, and a minimal redacted example. Do not send personal audio, a complete library database or real credentials.

There is no public supported stable release yet. Reports against the current development version are welcome. After a release, the latest published version will be the initial maintenance target; older versions are not promised backports.

The maintainer will assess reports, seek clarification where needed and coordinate disclosure with the reporter. No fixed response or remediation deadline is promised.
